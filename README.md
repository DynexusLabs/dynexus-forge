# Dynexus Forge

**Dynexus Forge** is the token creation module within the Dynexus ecosystem. It allows users to launch their own fungible tokens on the Aptos blockchain using the DYNA platform.

---

## ✨ Features

- Create custom fungible tokens with metadata
- Requires DYNA as a fee/payment token
- Permissionless — open to any user
- Built with Aptos Move for security and performance

---

## 🛠️ Tech

- Move smart contracts
- Compatible with Dynexus Core for governance integration
- Future: UI + Factory-as-a-Service deployment
